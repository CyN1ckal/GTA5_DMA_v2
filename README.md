A hobby project trying to utilize modern C++ for a GTA5 Enhanced DMA Mod Menu. Feel free to contribute.
Meant for single player with BattlEye turned off.

Goals:
1. Easy long term maintainability.
   I am using pattern scanning to dynamically resolve both pointers and offsets. In theory this should provide forward compatibility.
2. Clean and modern C++
   This goes hand and hand with #1. Write good code to make it simple to maintain. No restrictions on language set or features.
